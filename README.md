## 📌 What It Does

1. **Upload** a resume file (txt/pdf) or paste text directly
2. **AI analyzes** skills, sections, impact language, and quantification
3. **Get a score** (0–100) with grade (A/B/C/D)
4. **See suggestions** tailored for AI/ML engineer roles

---

## 🧠 AI/ML Concepts Demonstrated

- **NLP / Text Analysis** — keyword extraction, pattern matching, heuristic scoring
- **REST API Design** — file upload + JSON endpoints with FastAPI
- **Domain-Specific Intelligence** — scoring rubric designed for tech/AI roles
